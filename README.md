# BiblioNet Microservices System

## Opis projekta

BiblioNet predstavlja mikroservisni sistem za upravljanje pozajmljivanjem knjiga u bibliotekama, sa podrškom za rezervaciju knjiga koje su trenutno pozajmljene.

Projekat je u izradi - dokumentacija će biti dopunjena kako moduli budu dodavani.
